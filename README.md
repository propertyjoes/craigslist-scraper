# Craigslist Property Scraper

A Python-based automated system that:
- Scrapes furnished house listings from Sacramento Craigslist
- Extracts contact emails from listings
- Stores results in Google Sheets

## Features
- Automated email extraction using Selenium
- Google Sheets integration
- Railway-hosted cloud execution
